# Data

IBM HR Analytics Employee Attrition & Performance dataset.

Download: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Save as `data/ibm_hr_attrition.csv`. The pipeline expects this exact path.

Synthetic dataset — 1,470 rows, 35 columns, binary `Attrition` target (Yes/No), 16.1% positive class. No real employee records.
